Panduan Penggunaan Dashboard
1. Siapkan File TXT

Siapkan file laporan kehadiran dalam format .txt yang akan digunakan sebagai sumber data dashboard.

2. Upload Data

Pada menu Dashboard Utama, pilih Pilih / Upload File TXT. Beberapa file TXT dapat dipilih sekaligus.

3. Tunggu Proses Data

Dashboard akan membaca, menggabungkan, dan memproses data TXT. Data yang berhasil diproses akan digunakan oleh seluruh menu.

4. Kehadiran Siswa

Buka menu Kehadiran Siswa (KBM), kemudian pilih tanggal untuk melihat data ketidakhadiran siswa pada tanggal tersebut.

5. Rekapan dan Analisis

Gunakan menu Rekapan Siswa, Analisis Kelas, Kehadiran Guru, Rekapan Guru, dan Analisis Tren & Grafik untuk melihat hasil pengolahan data.

6. Muat Ulang Data

Jika file TXT yang sama ingin diproses kembali, gunakan tombol Muat Ulang Data.

Catatan: Dashboard menggunakan data TXT yang diunggah sebagai sumber data dan menggabungkan data yang terduplikasi.
